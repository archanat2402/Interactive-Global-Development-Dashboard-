# Does wealth buy health?
An interactive Plotly dashboard built for DS-2 (Data Visualisation).

**Question:** How are income and life expectancy related, how has that changed from 1952 to 2007, and who is still left behind?

**Dataset:** Gapminder (via `plotly.express.data.gapminder()`), 142 countries.

## Charts
1. Bubble scatter: GDP vs life expectancy (play button + year slider)
2. Line chart: life expectancy trend (continent dropdown)
3. Bar chart: top 10 countries (year dropdown)
4. Histogram: distribution in 1952 vs 2007
5. Box plot: spread within continents, 2007
6. Heatmap: median life expectancy by continent and year

## How to view
Download `dashboard.html` and open it in any browser (internet needed to load Plotly).
Notebook: `TASK_2.ipynb`
